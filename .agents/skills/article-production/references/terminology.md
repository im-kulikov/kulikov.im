# Реестр «секретных букв» канала «Домашний прод»

Правило канала: **термин или аббревиатура объясняется один раз за всю историю
публикаций**. Реестр живёт в `data/terms.yml` (в Git, рядом со скиллом) и
обновляется по мере выхода публикаций — коммитится вместе со статьёй.

## Схема

| Поле | Значение |
|---|---|
| `term` | каноническое написание |
| `definition` | утверждённое автором определение (расшифровка в скобках) |
| `aliases` | синонимы/расшифровки, которые тоже считаются «встречей» термина |
| `first_published_at` | дата публикации, где термин объяснён (ISO) |
| `first_article_id` | article-id той публикации |
| `first_telegram_url` | URL поста, где термин объяснён |
| `status` | `candidate` (обнаружен, ждёт определения) → `confirmed` (определение утверждено, ждёт публикации) → `published` (объяснён; повторно не объясняем) |

Исторические термины (объяснялись до ведения реестра) хранятся как
`status: published` с пустыми `first_*`.

## Как работать (`terms.mjs`)

```sh
# проверка текста: известные (term + aliases) и КАНДИДАТЫ
node .agents/skills/article-production/scripts/terms.mjs check tmp/drafts/<id>/telegram.md

# после утверждения определения автором
node .agents/skills/article-production/scripts/terms.mjs confirm <TERM> --definition "…" [--aliases "a,b"]

# только после фактической публикации
node .agents/skills/article-production/scripts/terms.mjs publish <TERM> \
  --article <id> --telegram-url https://t.me/…
```

- `known` со статусом `published` → определение **не повторять**.
- `candidates` — эвристика ВСЕ-КАПС токенов (латиница/кириллица/цифры/дефис,
  2–12 символов, вне стоп-слов и реестра; капс-префиксы смешанных слов вроде
  «MTP» из «MTProto» отсекаются). Это **подсказка автору, не автодобавление**:
  каждый кандидат выносится на review и либо подтверждается `confirm`,
  либо убирается из текста. `validate.mjs` блокирует пакет с неразрешёнными
  кандидатами.
- `confirm` защищён от дубликатов (по term и aliases, без учёта регистра);
  `publish` — от повторной публикации и от выдуманных URL (только t.me).
- В Telegram-заметке — короткая расшифровка в скобках при первом появлении;
  сложные объяснения — в статью на сайте.

## Начальный состав (исторические, `published`)

VPS, SSH, OTA, LLM, LoRA, DKMS, API, MTProto, ТСПУ, bug report, топик.
